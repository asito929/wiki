# ASITO WIKI

GitHub Pages에 올려 사용할 수 있는 아시토 전용 위키형 정적 사이트입니다.

## 파일 구조
- `index.html` : 아시토 메인 문서
- `content/sitoworld.html` : 시토월드상세 문서
- `style.css` : 공통 디자인
- `script.js` : 목차, 각주 팝업, 맨 위로 이동 등 공통 기능
- `assets/` : 프로필/캐릭터/이모티콘/구독 배지 이미지
- `profile-toc-side-layout.css` : 프로필, 목차 레이아웃
- `EDIT_NOTES.md` : 수정사항 업데이트

## 콘텐츠를 별도 문서로 빼는 기준
메인 문서에는 콘텐츠의 성격과 결과를 2~3문장 정도로 요약하고, 일자별 기록·에피소드·세부 진행은 `content/` 아래 상세 문서에 작성하는 것을 권장합니다.
